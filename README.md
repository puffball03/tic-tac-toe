### tic-tac-toe

Welcome to Tic Tac Toe! This is a 2 player game in which each player tries to achieve 3 in a row!

## How to run
Start the game by running python3 main.py  
Press enter to play, select your mode type using 1 for PvP and 2 for PvAI
    If playing PvAI elect your difficulty by typing Easy/Hard

## Testing
How to run the test suite!

# Optional: Setup a virtual environment

python3 -m venv .venv

# Install Requirements
pip install -r requirements.txt

# Run the tests

pytest
